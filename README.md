# 学生选课管理系统

基于 Vue 3 + Spring Boot + MySQL 的全栈容器化选课管理系统。

## 功能特性

- **用户认证**：
  - **管理员登录**：拥有系统所有权限。
  - **学生登录**：支持学生自主选课、查看已选课程、修改密码。
- **基础数据管理 (管理员)**：
  - **专业管理**：管理学校专业信息。
  - **课程管理**：管理课程信息，支持增删改查。
  - **学生管理**：管理学生基本信息，支持批量导入、密码重置。
- **选课管理**：
  - **管理员**：查看所有选课记录，录入成绩。
  - **学生**：在“可选课程”中进行选课，在“我的选课”中查看或退选（已录入成绩不可退选）。
- **统计分析 (管理员)**：
  - **图表展示**：集成 ECharts，直观展示各专业学生分布、课程选修情况等。
  - **班级成绩统计**：查询指定班级的成绩概况（总分、平均分）。
  - **补考名单查询**：查询指定专业的不及格学生名单。

## 技术栈

- **Frontend**: Vue 3, Element Plus, Vite, Nginx, ECharts
- **Backend**: Spring Boot 3, Spring Data JPA, **JDK 17 (Eclipse Temurin)**
- **Database**: MySQL 8.0

## 快速开始 (How to Run)

确保本地已安装 Docker 和 Docker Compose。

1. **构建并启动服务**

   ```bash
   docker compose up --build -d
   ```

   > 注意：建议首次运行或代码更新后使用 `--build` 参数，以确保镜像包含最新的依赖和代码变更。

2. **访问系统**

   - **Frontend**: http://localhost:3000
   - **Backend API**: http://localhost:8080

   - 使用 `admin / 123456` 登录。
   - 访问“统计分析”查看 ECharts 图表。
   - 在“学生管理”中添加新学生，并分配账号。

2. **学生功能验证**
